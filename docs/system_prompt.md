# Knewrall System Prompt

The canonical, harness-agnostic operating instructions now live in
[`INSTRUCTIONS.md`](../INSTRUCTIONS.md).

If your harness lets you set a custom system/base prompt, point it at
`INSTRUCTIONS.md` (or paste its contents). Otherwise the root pointer files
(`AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `.clinerules`) created by the installer
already reference it, so it is loaded automatically.
