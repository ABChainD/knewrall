# `workdesk/` — Working Desk (Intake)

A scratch/intake area you control. Drop **any** raw, random, or unstructured source
files here that you want the agents to work with: notes, dumps, exports, drafts,
screenshots, snippets — anything awaiting processing.

## Ownership
**You and the agents share this space.** Unlike `neurons/ notes/ media/ archive/`
(which Knewrall owns), the workdesk is yours to fill freely.

## What Knewrall does with it
The system scans the workdesk, then **analyzes, processes, and structures** what it
finds — creating/updating Neurons, producing finished Notes, and (when appropriate)
moving retained files into [`../media/`](../media/README.md) or
[`../archive/`](../archive/README.md). Treat the workdesk as **transient**: items
here are expected to be consumed and cleared, not stored long-term.

## Layout
Free-form. Organize it however you like — Knewrall imposes no sub-foldering scheme
here.
